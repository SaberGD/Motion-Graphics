# Copy-ready prompt recipes

Use these with the master instructions. Replace bracketed values with an approved brief; missing facts remain missing. A negative-prompt field is optional and tool-dependent: when absent, append the exclusions to the main prompt.

## A. General composition / editing agent

Create a [15-second / 30-second] [1080x1920 / 1920x1080] Arabic-first motion graphic for [Saber Group Academy / MARO AI], using the supplied Saber Group motion kit. Read 01-MASTER-INSTRUCTIONS.txt, brand-tokens.json and the asset manifest. The only approved message is [message]. Exact on-screen copy: [copy]. Exact CTA: [CTA and verified URL].

Use the original supplied wordmark as a locked image, Cairo for Arabic and Bebas Neue for short English labels. Charcoal #0A0A0A, warm red #C4321F, off-white #F6F3F2 and a small #FF8A1F accent. Quiet grid, restrained technical corners, generous negative space, modest Arabic type. One visual idea per scene. No logo redraw, random palette, excessive glow, crowded HUD or giant Arabic text.

Use a 25fps timeline, ease-out cubic-bezier(0.16,1,0.3,1), 12-frame entrances, 8-frame exits, and a readable final card held for at least 2 seconds. Use [no mascot / the supplied MARO-WAVE image] without deformation. Return a timed scene table and one style frame first. State any unsupported output feature before rendering. Then deliver the actual MP4, editable composition when supported, clean motion plate and exact text list. Do not invent a price, result, testimonial, deadline, phone number or product capability.

## B. Textless generative plate - academy

Create one restrained motion-graphics background plate for Saber Group Academy, [duration supported by this tool], [aspect ratio]. Near-black #0A0A0A background, a very faint burgundy edge wash, thin warm-white construction grid at low opacity, one short warm-red #C4321F line reveal, and tiny orange #FF8A1F corner accents. Clean editorial technology direction, precise alignment, ample empty space at [text area from the brief]. Locked camera, no sudden zoom, no fast movement, no object morphing. Keep the main copy and logo areas empty throughout. The exact brand logo and Arabic text will be added as original assets in compositing; do not generate them.

Exclusions: text, Arabic lettering, Latin lettering, logos, watermarks, numerals, purple or blue neon, sci-fi dashboard clutter, floating orbs, bokeh blobs, heavy lens flare, particles, flashing, loud transitions, busy geometry, fake UI screenshots.

## D. Brand-consistency repair pass

Compare the supplied result against 01-MASTER-INSTRUCTIONS.txt, the exact logo and the selected reference frame. List only concrete deviations, then correct them without changing approved copy or claims. Check logo aspect ratio/color, Arabic shaping and RTL/LTR isolation, text size, palette, grid opacity, safe margins, mascot consistency, motion restraint, duration and final hold. Do not solve a contrast problem by recoloring the logo or adding large glows. Preserve all correct elements. Return a pass/fail checklist and clearly flag anything the current tool cannot fix.
