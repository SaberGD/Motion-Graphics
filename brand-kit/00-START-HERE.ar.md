# باكدج اتجاه الموشن لصابر جروب

إصدار 1.0 - مراجعة 3 نوفمبر 2026.

تحديث المرفقات: أضفنا اللوجو المربع الذي أرسله صاحب الهوية داخل `assets/logos/saber-group-academy-square-original.png`، كما هو تمامًا بخلفيته الأصلية، مع الاحتفاظ بكل الأصول السابقة. تعريفه واستخدامه موجودان في خريطة الأصول والـManifest.

دي قواعد إنتاج مقترحة مبنية على الهوية الفعلية في مارو والترينينج والحسابات وموقع الأكاديمية. الألوان واللوجوهات والخطوط مستخرجة من المصادر؛ التوقيتات، مقاسات النص للفيديو، المساحات الآمنة والستوريبورد تنظيم جديد للإنتاج، مش دليل رسمي قديم.

## تستخدمها إزاي؟

**بما إنك هتستخدم Claude:** ابدأ بملف `07-CLAUDE-SETUP.ar.md`. الصق `CLAUDE-PROJECT-INSTRUCTIONS.txt` في تعليمات الـProject، وارفع الملفات المرجعية المطلوبة. الدليل يفرق بين Claude Motion لو متاح في خطتك، وClaude Code للتنفيذ المحلي، والشات العادي للتخطيط.

1. ارفع `01-MASTER-INSTRUCTIONS.txt` في خانة Instructions / System Prompt لو الأداة بتدعمها. أو ابعته في بداية المشروع كتعليمات مرجعية.
2. ارفق `brand-tokens.json` و`ASSET-MANIFEST.json`، ومعاهم اللوجو ومرجع بصري واحد أو اتنين. استخدم ملف الخط داخل الرندر أو المحرر الداعم؛ رفع TTF في الشات مش ضمان لتشغيله. مش لازم ترفع الباكدج كلها لو الأداة بتحدد عدد المرفقات.
3. انسخ بريف `02-PROJECT-BRIEF.ar.md`، واملأ الهدف والنص والمدة والمقاس والـCTA. حدّد هل الفيديو للأكاديمية ولا لمارو. اكتب المعلومات الحالية المعتمدة بدل ما الأداة تسحب أسعار أو عروض قديمة.
4. اختار مسار التنفيذ من `03-TOOL-WORKFLOWS.ar.md`: أداة بتعمل مونتاج بطبقات، أو مولّد فيديو محتاج كومبوزيت بعده.
5. راجع فريم ثابت، بعده ستوريبورد، وبعدهم الفيديو. استخدم `06-PRE-FLIGHT-CHECKLIST.md` قبل النشر.

## أقل مرفقات لازمة

| نوع الفيديو | الملفات |
| --- | --- |
| إعلان للأكاديمية | Master Instructions + Brief + `saber-group-wordmark.png` + Cairo + فريم Academy مرجعي |
| فيديو لمارو | نفس الملفات + صورة Maro الأصلية + فريم Maro مرجعي |
| مولّد لا يقبل خطوط | تعليمات الهوية + صورة مرجعية + طلب مشاهد بدون كتابة؛ النص واللوجو يتركّبوا بعد التوليد |
| أداة محدودة بعدد الصور | اللوجو + فريم الاتجاه المناسب + مرجع مارو فقط لو موضوع الفيديو يحتاجه |

الملفات المضغوطة مش بتتفهم تلقائيًا في كل أداة. فك الضغط وارفع الملفات المطلوبة. ملفات TTF قابلة للتثبيت في أدوات التصميم؛ بعض مولدات الفيديو لا تستخدمها حتى لو تم إرفاقها.

## مهم جدًا

- البرومبت لوحده مش ضمان للحفاظ على الهوية. أدق نتيجة: خلفية وحركة من AI، ولوجو وكتابة عربية كطبقات أصلية في المونتاج.
- صور مارو المرفقة أصلية ومعاها قناة Alpha حسب الملف، لكن بعضها يحتوي هالة لونية. ده مش موديل 3D ولا Rig مفصول، وما ينفعش نسميه كده. استخدمه كصورة ثابتة تتحرك أو كمرجع هوية.
- لم أجد ماستر لوجو SVG/AI أصلي في الملفات البصرية المحددة بالريبوهات. المرفق WebP أصلي وPNG مشتق منه، مش فيكتور متحوّل شكليًا ولا لوجو معاد رسمه.
- النسخة البيضاء/البرتقالية لا تتحول للأسود في الفاتح. استخدم لوحة فحمية خلفها بدل تغيير ألوانها.
- الاختلافات بين ثيمات الحسابات والترينينج مش كلها ألوان تسويقية. اخترنا بروفايل موشن موحّد بدل خلط كل ألوان الـCSS.
- لا توجد أسعار، عروض، شهادات، أرقام مبيعات أو أرقام تواصل معتمدة تلقائيًا داخل الأمثلة. الـCTA الافتراضي هو الموقع العام.
- الأمثلة والفيديو القصير مراجع اتجاه صممتها للباكدج؛ ليست لقطات من حملة منشورة ولا شهادة أن كل أداة AI ستنفذها حرفيًا.

## محتويات التسليم

- `01-MASTER-INSTRUCTIONS.txt`: تعليمات إنجليزية دقيقة، مع ضوابط العربي والهوية.
- `02-PROJECT-BRIEF.ar.md`: بريف يتكرر مع كل فيديو.
- `03-TOOL-WORKFLOWS.ar.md`: طريقة العمل حسب قدرات الأداة.
- `04-PROMPT-RECIPES.md`: برومبتات قابلة للنسخ.
- `05-STORYBOARD-EXAMPLES.ar.md`: أمثلة 15 و30 ثانية.
- `06-PRE-FLIGHT-CHECKLIST.md`: مراجعة نهائية.
- `07-CLAUDE-SETUP.ar.md`: إعداد Claude Project ومسارات Motion وCode والشات.
- `CLAUDE-PROJECT-INSTRUCTIONS.txt`: نص جاهز لخانة تعليمات المشروع.
- `CLAUDE.md`: تعليمات التنفيذ المحلي لـClaude Code.
- `brand-tokens.json`: ألوان وخطوط وحركة ومساحات آمنة بصيغة منظمة.
- `ASSET-MANIFEST.json` و`ASSET-MAP.ar.md`: تعريف كل أصل ودوره ومصدره وحدوده.
- `assets/`: اللوجو، مارو، خطوط، أيقونات، جريد وزوايا.
- `references/`: فريمات اتجاه ثابتة، فيديو حركة صامت، وأدلة بصرية.
- `index.html`: معرض محلي للاتجاه، والخطوط والأصول ومعاينة الحركة.
- `SOURCE-AUDIT.json` و`SOURCE-NOTES.ar.md`: مراجع وأرقام الـcommits والفرق بين المنقول والمقترح.

لم يتم تغيير أو نشر أي من أنظمتك، ولم يتم تضمين API keys أو ملفات سيرفر أو بيانات عملاء أو طلاب.
