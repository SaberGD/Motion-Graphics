# إعلان HORIX One (موشن جرافيك)

إعلان مدته 58 ثانية، مقاس 1080×1920 و60 فريم. الفكرة: «اشتغل على تصميمك واتنقّل بيه بين Vector وPixel براحتك».
مصمم بيعمل براند قهوة اسمه «بُنّ»: يرسم اللوجو في Vector، ويحطه على صورة المنتج في Pixel، ويرجع لـVector يقفل البوستر والحملة.

النسخة الجاهزة: `output/horix_one_promo.mp4`.

## السيناريو
كل التوقيتات على شبكة 88 BPM، بنفس `B(n)` اللي في إعلان البحيري. علشان كده قصّة الموسيقى بتاعته (`music60.wav`) بتركب على الإعلان ده من غير أي تعديل.

| بار | الوقت | المشهد |
|---|---|---|
| 0–1 | 0–5.4 | **الطريقة القديمة:** برنامجين والملفات بتطير بينهم (Export… Import… Missing fonts). «بتصدّر. بتفتح. بتصدّر تاني؟ والخط ضاع.» |
| 2–3 | 5.4–10.8 | الاتنين يتشفطوا في نقطة أمبر، والشاشة تبقى أمبر: «برنامج واحد.» بعدها تطلع نافذة HORIX One، والشريط يتنقّل Vector ← Pixel ← Vector |
| 4–7 | 10.8–21.7 | **Vector:** القلم بيرسم حبة البن نقطة نقطة على الإيقاع، والشكل يتملي، والخط يترسم، و«بُنّ» تتكتب حرف حرف. بعدها زووم 1600% على حرف الشكل، والخط يفضل حاد |
| 8–11 | 21.7–32.6 | **النقلة:** ضغطة على «افتح التصميم في Pixel». اللوجو يطلع من النافذة ويتفتت مربعات بكسل، ويرجع يتجمّع في Pixel، والطبقات تظهر كطبقات أشكال. بعدها Vector/Pixel على 4 ضربات: «اتنقّل بينهم براحتك.» |
| 12–15 | 32.6–43.5 | **Pixel:** صورة الكوباية، والتحديد بالـAI، والخلفية تختفي مربعات وتيجي خلفية جديدة، واللوجو يطير ويتطبع على الكوباية. وعلى كل ضربة تعديل: سطوع، ودفا، وتباين، وإطار غامق |
| 16–18 | 43.5–51.7 | «افتح الصورة في Vector»، وQuick Export as PNG، والصورة تدخل إطار البوستر. وبعدها الحملة: بوست، وستوري، ولافتة، ومنيو |
| 19–21 | 51.7–58.2 | «Vector.» يترسم منحنى القلم، و«Pixel.» تطلع المربعات، و«One.» ييجي المربع الأحمر، وبعدها أيقونة HORIX One تكمل نفسها. ثم HORIX ONE، و«ويب · ويندوز · ماك»، و`one.horix.live`، و«Layout قريبًا» |

الإعلان ملتزم باللي البرنامج بيعمله فعلًا في الإصدار 0.2 (`apps/horix-one/README.md` في maro-studio-):
- النقل بزرار.
- النص بيدخل Pixel أشكال.
- من Pixel لـVector الشغل بيروح صورة PNG.
- Layout «قريبًا».

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | الستايلات، بألوان HORIX One وخطوطه: Cairo وInter وBarlow Condensed |
| `scenes.js` | كل المشاهد. كل فريم دالة في الوقت `render(t)` |
| `engine.js` | محرك الحركة، منقول من `scenes-v2/engine2.js` في El.-Behery-Media ومضاف له مؤشر الماوس |
| `logo.js` | لوجو «بُنّ». تعريف واحد بيستخدمه الـSVG، والمربعات اللي بيتفتت لها، والطبعة اللي على الكوباية |
| `icons.js` | أيقونات خطية بنفس ستايل البرنامج |
| `cup/` | صورة المنتج متعملة 3D بـthree.js (`render_cup.cjs`)، وحدود الكوباية للتحديد بالـAI (`outline.py`) |
| `sfx.py` | المؤثرات الصوتية متزامنة مع المشاهد، ومعاها بيت إيقاع مؤقت 88 BPM |
| `render.cjs` و`build.sh` | الرندر بـPlaywright، والتجميع |

## التشغيل
```bash
npm install                      # three.js والخطوط
pip install opencv-python-headless numpy pillow
node cup/render_cup.cjs && python3 cup/outline.py   # لو عايز تعيد صور الكوباية
./build.sh ../output/horix_one_promo.mp4             # بالإيقاع المؤقت
./build.sh ../output/horix_one_promo.mp4 music60.wav # بموسيقى البحيري (أو أي تراك على نفس الشبكة)
node render.cjs stills 12,25,40 /tmp/st              # صور ثابتة للمراجعة
```
`build.sh` بيقسم الرندر على 4 أجزاء شغالة مع بعض، وبياخد حوالي 10 دقايق.
