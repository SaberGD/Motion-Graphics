# Lip Filler — Motion Graphics (9:16, 1080x1920, 30fps, 27.53s)

## Output (`output/`)
| File | What it is |
|---|---|
| `lip_filler_yellow.mp4` | Yellow blazer: lower-third motion titles + B-rolls + music/SFX (no captions) |
| `lip_filler_green.mp4` | Same for the green blazer |
| `stems/voice.wav` | Original voice, untouched (bit-exact copy) |
| `stems/music.wav`, `stems/sfx.wav` | Music bed and SFX, already ducked, for remixing |
| `stems/mix.wav` | Final mix used in the MP4s |

v2 (client notes): captions removed, all motion titles moved down to the lower third,
fewer titles with longer and calmer holds, camera punch-ins and shakes removed, whooshes about 8 dB softer.
Caption tooling (`scripts/captions.py`, `?caps=1`) is still in the project if captions are needed later.

## Project (`project/`)
The edit is built as code, so any change re-renders the whole video in about 4 minutes.
- `index.html`: the whole composition. Every timing is in the `T` object; B-roll slots and offsets are in `BROLL`.
  Colours are CSS variables in `:root`.
- `captions.json`: generated by `scripts/captions.py` from `source/transcript_timed_ar.txt`
  (`CHUNKS` sets the caption breaks; `KEY_AR` sets the highlighted words).
- `scripts/audio.py`: synthesised music + SFX (royalty-free, no samples) mixed under the voice.
- `scripts/render.mjs`: renders frames with headless Chromium. `scripts/make.sh`: full build + encode.

```bash
cd project && scripts/make.sh /path/to/Saber_Motion_Pack
```
Live preview: serve `project/` (for example `python3 -m http.server`) and open `index.html?play=1&caps=1`.

## Notes
- The "AI" mark in the top-left corner was removed from the doctor plates (delogo on the smooth wall area).
- B-rolls play at native speed (24fps clip on a 30fps timeline, no stretch or slow-mo); only a 1.9–4s window of each 4s clip is used.
- Voice is not processed at all. Music/SFX are ducked under speech and pulled down wherever voice + bed would clip.
- Caption word timing is interpolated inside each line of the timed transcript.
